# firezunda bot Release Notes

## 2026-07-11 Public Release

今回のリリースでは、Discord 上での通知、地震情報、ニコニコ関連通知、ダイスロール、メッセージ解析まわりを中心に改善しました。

## 新機能

### Slash Command 対応

一部の機能を `/` から始まる Slash Command として使えるようになりました。

例:

```text
/roll expression:1d100
```

### ダイスロール

これまで通り通常メッセージとして投稿しても実行できます。

```text
1d100
2d6+3
```

コマンドとしても利用できます。

```text
/roll 1d20+5
```

### ニコニコ動画の投稿通知

指定されたニコニコ動画ユーザの新規投稿を通知できるようになりました。
※ RSSの廃止に伴い再度作成しました。(ひっそりと廃止するの止めてくれません?)
:zundamochi: 新しい動画投稿を定期的に確認します。
:zundamochi: ショート動画の投稿も確認します。
:zundamochi: ユーザごとに通知先を分けられます。
:zundamochi: 同じ動画が繰り返し通知されないようになっています。

### ニコニコインフォ通知

ニコニコインフォの記事通知に対応しました。
※ RSSの縮小に伴い再度作成しました。
:zundamochi: メンテナンス情報などのカテゴリを定期的に確認します。
:zundamochi: 必要に応じて通知対象を絞り込めます。
:zundamochi: 通知ではリンクの下に記事内容の約500文字要約を表示します。
:zundamochi: 既に通知した記事は再通知されません。

### 予定イベント取り込み
[ボイイベまとめ](https://vo.nrsy.jp/) を元に作成しているギルドカレンダーですが、
APIの存在が不安定なためカレンダーを元に作成するように変更致しました。

イベント情報をサーバ上で確認しやすくなります。

### メッセージ解析

Bot がメッセージの傾向を解析できるようになりました。

解析結果は、通知や今後のコミュニケーション傾向分析に利用されます。
分析結果後、酷い場合はbotから通知をするようにしております。
※ 本機能に関しまして炎上の抑止として追加した機能となります。


## 改善

### 地震情報画像

地震情報画像を生成する様に致しました。


### ニコニコ動画投稿取得

ニコニコ動画の投稿情報取得方法を見直し、より安定して取得できるようにしました。

これにより、一部ユーザで投稿情報を取得できない問題が起きにくくなっています。

ユーザ動画投稿通知は、毎時 `00` / `15` / `30` / `45` 分に実行するようにしました。

## 修正

:zundamochi: ニコニコ動画の投稿情報が取得できないことがある問題を改善しました。
:zundamochi: ニコニコインフォ通知で、同じ記事が繰り返し通知されないようにしました。

## 利用者向けメモ

:zundamochi: ダイスロールは通常メッセージでも `/roll` でも使えます。
:zundamochi: 新しい Slash Command が見えない場合は、少し時間を置いてから Discord を再読み込みしてください。
:zundamochi: 通知の有効化や通知先の変更は、サーバ管理者に依頼してください。
:zundamochi: ニコニコ関連通知やコミュニケーション傾向分析は、サーバ側で有効化されている場合に利用されます。
:zundamochi: 津波情報も発生頻度が非常に少ないため未検証なのだ(データフォーマットが複数あるからどれが採用されてるのかが分からん)
