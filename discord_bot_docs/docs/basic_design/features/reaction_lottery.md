# リアクション抽選設計

## 概要

Discord メッセージに付与された応募リアクションをもとに、指定時刻または手動終了時に当選者を抽選する。
抽選状態はメモリ上で管理し、永続化は行わない。

## 構成

| 項目 | 内容 |
|---|---|
| Cog | `ReactionLotteryCog` |
| Service | `ReactionLotteryService` |
| テーブル | なし |

## コマンド

| 種別 | 名前 | 内容 |
|---|---|---|
| Command Group | `lottery` | 使用方法を表示する。 |
| Command | `lottery start` | 抽選募集メッセージを投稿し、応募リアクションを付与する。 |
| Command | `lottery end` | 実行中の抽選を早期終了する。 |

## 処理方針

| 処理 | 内容 |
|---|---|
| 終了時刻解析 | `30m`、`2h`、`1d` などの相対時間、または日時文字列を UTC aware datetime に変換する。 |
| 期限検証 | 終了時刻は未来かつ 7 日以内に制限する。 |
| 応募受付 | 抽選メッセージに既定リアクションを付与し、同リアクションの利用者を応募者として扱う。 |
| 当選者選定 | Bot を除外し、重複しない利用者から指定人数までランダム抽選する。 |
| 早期終了 | 作成者またはメッセージ管理権限を持つ利用者のみ許可する。 |
