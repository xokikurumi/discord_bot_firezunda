# コマンド提供要件

## 1. 概要

主要操作を prefix command と slash command の両方、または機能に応じた適切な形式で提供する。

## 2. 機能要求

| ID | 要件 |
|---|---|
| FR-CMD-001 | 主要な操作は Discord コマンドとして実行できること。 |
| FR-CMD-002 | 管理操作は Discord の管理者権限を要求できること。 |
| FR-CMD-003 | 起動時に slash command を同期できること。 |
| FR-CMD-004 | コマンド引数が不正な場合、利用者へ分かる形でエラーを返せること。 |
| FR-CMD-005 | コマンド一覧を文書化し、現在利用できる操作を確認できること。 |

## 3. 権限区分

| 区分 | 内容 |
|---|---|
| 管理者操作 | 設定追加、設定削除、有効化、無効化、手動同期 |
| 一般操作 | 一覧確認、ヘルプ確認、ダイスロール |
| 自動処理 | メッセージ受信、ボイス状態変更、定期確認、外部イベント受信 |
