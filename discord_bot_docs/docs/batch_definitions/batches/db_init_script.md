# DB 初期化スクリプト

## 1. 基本情報

| 項目 | 内容 |
|---|---|
| バッチ ID | BATCH-012 |
| 処理名 | DB 初期化スクリプト |
| 実装 | `db/init_db.py` |
| 実行方式 | 手動スクリプト |
| 起動契機 | 開発・保守時 |

## 2. 処理概要

DB 接続確認を行い、ORM 定義に基づいて不足テーブルを作成します。

## 3. 実行例

```bash
python db/init_db.py
```

## 4. 利用可能な関数

| 関数 | 内容 |
|---|---|
| `check_connection` | `SELECT 1` で DB 接続を確認する |
| `init_db` | ORM 定義から不足テーブルを作成する |
| `drop_db` | ORM 定義対象テーブルを削除する |
| `reset_db` | テーブル削除後に再作成する |

## 5. 注意事項

`drop_db` と `reset_db` は開発用途です。
本番環境では実行しないでください。
