# 起動・初期化設計

## 起動処理

| 順序 | 処理 | 内容 |
|---:|---|---|
| 1 | Bot インスタンス作成 | `discord.Intents` と prefix `!` を設定する。 |
| 2 | DB 初期化 | `Base.metadata.create_all` で不足テーブルを作成する。 |
| 3 | スキーマ移行 | `run_schema_migrations` で既存 DB の不足カラム・インデックスを補正する。 |
| 4 | Service 生成 | `Container` が各 Service を生成する。 |
| 5 | Cog 登録 | メッセージ、通知、タスク系 Cog を Bot に登録する。 |
| 6 | Slash command 同期 | 起動後 `on_ready` でグローバルおよびギルド別同期を行う。 |
| 7 | Bot 起動 | Discord token で接続し、イベント処理を開始する。 |

## 初期化対象

| 対象 | 内容 |
|---|---|
| DB テーブル | SQLAlchemy モデル定義に基づくテーブルを作成する。 |
| スキーマ差分 | 既存環境向けに不足カラム・ユニークインデックスを追加する。 |
| Slash command | グローバル同期後、設定に応じて参加ギルドにも同期する。 |
| バックグラウンドタスク | Cog 読み込み時に各監視・定期実行タスクを開始する。 |
