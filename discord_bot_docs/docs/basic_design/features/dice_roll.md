# ダイスロール設計

## 概要

`d20` パーサーを利用し、ダイス式を評価する。コマンド実行と自動ロールの両方に対応する。

## 構成

| 項目 | 内容 |
|---|---|
| Cog | `DiceRollCog` |
| Service | `DiceRollService` |
| テーブル | なし |

## コマンド・イベント

| 種別 | 名前 | 内容 |
|---|---|---|
| Command | `roll`, `dice` | 入力されたダイス式を評価する。 |
| Event | `on_message` | メッセージ本文がダイス式のみの場合に自動評価する。 |
