# 運用要件

## 1. CI/CD

| ID | 要件 |
|---|---|
| OPS-CI-001 | Markdown の形式検証を CI で実行できること。 |
| OPS-CI-002 | ドキュメントサイトを CI でビルドし、リンク切れやナビ不整合を検出できること。 |
| OPS-CI-003 | リリース対象ブランチとタグに応じたジョブ実行条件を定義できること。 |

## 2. リリース

| ID | 要件 |
|---|---|
| OPS-REL-001 | リリース前に差分確認、依存関係確認、設定確認を実施できること。 |
| OPS-REL-002 | リリース手順、ロールバック手順、保守手順を文書化すること。 |
| OPS-REL-003 | 本番反映前に必要な DB 初期化またはスキーマ補正を確認できること。 |

## 3. 監視・障害対応

| ID | 要件 |
|---|---|
| OPS-MON-001 | Bot 起動失敗、DB 接続失敗、外部 API 失敗をログから確認できること。 |
| OPS-MON-002 | 定期処理の最終実行状態を DB またはログから確認できること。 |
| OPS-MON-003 | Discord token 漏えい時は token を再発行して反映できること。 |
| OPS-MON-004 | 外部サービス障害時は対象機能を一時停止または次回実行へ持ち越せること。 |
