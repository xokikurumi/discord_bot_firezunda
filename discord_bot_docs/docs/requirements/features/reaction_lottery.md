# リアクション抽選要件

## 1. 概要

Discord サーバー内で、指定した応募リアクションを付けた利用者から当選者を抽選できるようにする。

## 2. 機能要求

| ID | 要件 |
|---|---|
| FR-LOTTERY-001 | 利用者はコマンドで抽選メッセージを作成できること。 |
| FR-LOTTERY-002 | 抽選には当選人数、終了時刻、タイトルを指定できること。 |
| FR-LOTTERY-003 | 終了時刻は相対時間または日時で指定できること。 |
| FR-LOTTERY-004 | 抽選終了時に応募リアクションを付けた利用者から当選者をランダムに選べること。 |
| FR-LOTTERY-005 | Bot ユーザーは抽選対象から除外できること。 |
| FR-LOTTERY-006 | 作成者またはメッセージ管理権限を持つ利用者は抽選を早期終了できること。 |
| FR-LOTTERY-007 | 抽選終了日時は未来かつ上限期間内であることを検証できること。 |

## 3. 入出力

| 区分 | 内容 |
|---|---|
| 入力 | 抽選開始コマンド、抽選終了コマンド、応募リアクション |
| 出力 | 抽選募集メッセージ、抽選結果メッセージ |
