# エラー処理設計

| 区分 | 方針 |
|---|---|
| Discord 権限不足 | コマンドエラーハンドラでユーザーに通知する。 |
| 外部 API 失敗 | 例外を捕捉しログ出力後、次回実行で再試行する。 |
| 通知失敗 | 送信済みフラグを更新せず、後続チェックで再送できる状態を維持する。 |
| DB 差分 | 起動時の軽量マイグレーションで不足カラム・インデックスを補正する。 |
| CI/CD | 必須変数、絶対パス、Runner 種別、書き込み権限を検証する。 |

## コマンドエラー

- 管理者権限が必要なコマンドは `commands.has_guild_permissions(administrator=True)` で制御する。
- エラー発生時は各 Cog の error handler でユーザー向けメッセージを返す。
