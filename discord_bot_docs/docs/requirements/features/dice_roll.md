# ダイスロール要件

## 1. 概要

利用者が Discord 上でダイス式を評価し、結果をメッセージとして確認できるようにする。

## 2. 機能要求

| ID | 要件 |
|---|---|
| FR-DICE-001 | 利用者はコマンドでダイス式を指定してロールできること。 |
| FR-DICE-002 | メッセージ本文がダイス式のみの場合、自動でロールできること。 |
| FR-DICE-003 | 不正なダイス式はエラーとして扱い、利用者へ通知できること。 |
| FR-DICE-004 | ロール結果には式、各ダイスの結果、合計値を含めること。 |
| FR-DICE-005 | 過度に大きい式や処理負荷の高い式を制限できること。 |

## 3. 入出力

| 区分 | 内容 |
|---|---|
| 入力 | ダイス式、メッセージ本文 |
| 出力 | ロール結果メッセージ |
