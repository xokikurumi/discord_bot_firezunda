# システム共通要件

## 1. 概要

Bot は Discord サーバー内のメッセージ、ボイス状態、リアクション、通知設定、外部サービス連携を扱う。
管理者は各種設定と同期処理を操作し、一般利用者はサーバー内で提供されるコマンドと自動応答を利用する。

## 2. 利用者

| 利用者 | 要件 |
|---|---|
| サーバー管理者 | 通知先、リアクション、外部連携、定期処理の設定を管理できること。 |
| 一般利用者 | 許可されたコマンド、リアクション、自動通知を利用できること。 |
| 運用担当者 | 起動、停止、リリース、復旧、ログ確認を実施できること。 |

## 3. 共通機能要求

| ID | 要件 |
|---|---|
| FR-SYS-001 | Bot は Discord API に接続し、サーバー内イベントを受信できること。 |
| FR-SYS-002 | Bot は起動時に必要な DB 初期化と軽量なスキーマ補正を実行できること。 |
| FR-SYS-003 | Bot は機能単位の Cog を登録し、コマンドとイベントハンドラを利用可能にできること。 |
| FR-SYS-004 | Bot は外部サービス連携に失敗しても、可能な範囲で他機能の稼働を継続できること。 |
| FR-SYS-005 | 管理操作は Discord の権限に基づいて制御できること。 |

## 4. 前提条件

| ID | 要件 |
|---|---|
| FR-SYS-PRE-001 | Bot token、DB 接続情報、外部 API 設定は環境変数または運用設定で管理できること。 |
| FR-SYS-PRE-002 | メッセージ、メンバー、リアクション、ボイス状態に関する Intent を利用できること。 |
| FR-SYS-PRE-003 | MySQL 互換 DB を利用できること。 |
| FR-SYS-PRE-004 | P2PQuake、Geolonia、気象庁関連ページ、Niconico、Ollama、ICS URL へ接続できること。 |
